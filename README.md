# Júlia's Archive

Crie um site romântico e autoral chamado provisoriamente “Entre Nós”, feito como uma experiência digital pessoal para minha namorada, Júlia.

IMPORTANTE: não quero um site parecido com Warthinha, nem uma cópia de modelos tradicionais de “site para namorada”. Evite completamente a estrutura clichê de:

“nossa história” como uma timeline convencional;

“10 motivos para te amar”;

contador de namoro como elemento principal;

mural de fotos;

playlist como seção principal;

chuva de corações;

excesso de rosa/vermelho;

frases românticas genéricas;

layouts que pareçam template pronto de Dia dos Namorados.

O objetivo é criar algo que pareça ter sido construído exclusivamente por uma pessoa para outra.

CONCEITO

O site deve parecer uma espécie de arquivo digital íntimo e secreto sobre a Júlia e sobre a relação.

A sensação deve ser:
“eu encontrei um lugar que alguém construiu cuidadosamente para guardar coisas que normalmente não caberiam em uma conversa.”

Quero que o usuário tenha vontade de explorar o site, descobrir coisas e clicar nos elementos. Não quero simplesmente uma página longa para rolar.

IDENTIDADE VISUAL

Crie uma estética sofisticada, íntima e cinematográfica.

Use:

fundo predominantemente off-white, creme ou tons muito suaves;

preto/grafite para textos;

detalhes em uma cor de destaque muito sutil;

tipografia serifada elegante para títulos;

uma sans-serif limpa para textos;

pequenos detalhes manuscritos apenas quando fizer sentido;

bastante espaço negativo;

animações suaves;

transições lentas e delicadas;

elementos que pareçam físicos/digitais ao mesmo tempo.

Não quero aparência de dashboard corporativo.

Também não quero uma estética infantil.

A interface deve parecer uma mistura de:
arquivo pessoal + diário + exposição de memórias + carta digital.

PÁGINA INICIAL

A primeira tela deve ser extremamente minimalista.

Mostrar apenas:

“Júlia.”

e abaixo:

“Eu fiz um lugar para guardar algumas coisas que não cabiam em uma conversa.”

Um botão:

“entrar”

Ao clicar, fazer uma transição elegante para o interior do site.

Não colocar dezenas de informações na primeira tela.

NAVEGAÇÃO

Depois de entrar, criar uma interface de navegação minimalista.

Em vez de menu tradicional com:
Home / Fotos / Cartas / Música / História

usar categorias mais autorais, por exemplo:

ARQUIVO
COISAS QUE GUARDEI
AINDA NÃO ACONTECEU
PARA LER
ENTRE NÓS

Esses nomes podem ser refinados visualmente.

EXPERIÊNCIA “ARQUIVO”

Criar uma página que pareça um arquivo pessoal.

Mostrar pequenos registros como:

“uma coisa que pensei e nunca te contei”
“um detalhe seu que ficou comigo”
“uma conversa que eu ainda lembro”
“uma coisa que mudou depois de você”
“um momento específico”
“uma coisa que eu quero lembrar para sempre”

Cada item deve parecer um documento/registro arquivado.

Ao clicar, abrir uma experiência de leitura elegante.

O conteúdo deve ser facilmente editável posteriormente.

EXPERIÊNCIA “COISAS QUE GUARDEI”

Esta seção deve ser sobre pequenos detalhes da Júlia que foram percebidos e guardados.

Não usar uma lista convencional.

Criar cartões ou pequenos objetos digitais.

Exemplo:

“o jeito que você fala quando está com vergonha”

“uma palavra que você sempre usa”

“uma coisa que você me contou uma vez”

“um jeito seu que eu acho bonito”

Cada item pode abrir uma pequena nota.

A ideia é transmitir atenção aos detalhes, não simplesmente fazer elogios.

EXPERIÊNCIA “AINDA NÃO ACONTECEU”

Criar uma seção dedicada ao futuro.

Mostrar acontecimentos que ainda não aconteceram como se fossem registros bloqueados.

Exemplos:

“primeira foto juntos”
“primeiro abraço”
“primeira viagem”
“um lugar que ainda vamos conhecer”
“uma memória que ainda não existe”

Cada item deve aparecer como:

AINDA NÃO DESBLOQUEADO

Quando clicado, pode mostrar uma pequena mensagem sobre aquele momento futuro.

Quero que essa seção possa ser atualizada futuramente conforme novas memórias aconteçam.

EXPERIÊNCIA “PARA LER”

Criar uma espécie de coleção de cartas.

Mas não quero envelopes clichês espalhados pela tela.

Quero algo mais parecido com documentos privados ou correspondências pessoais.

Exemplos de cartas:

“para quando sentir saudade”
“uma coisa que eu precisava te dizer”
“sobre você”
“sobre nós”
“uma carta para o futuro”

Cada carta abre em uma experiência de leitura imersiva.

As cartas devem ser armazenadas de forma que eu possa adicionar novas cartas facilmente.

EXPERIÊNCIA “ENTRE NÓS”

Esta deve ser a parte mais experimental do site.

Criar uma área que represente coisas que existem apenas entre duas pessoas.

Pode conter:

pequenas referências internas;

frases;

acontecimentos;

piadas internas;

músicas;

imagens;

pequenos textos;

detalhes que só nós dois entenderíamos.

Não preencher com conteúdo genérico.

Criar a estrutura para que eu possa inserir esses conteúdos depois.

MICROINTERAÇÕES

Quero muitas microinterações, mas extremamente discretas.

Exemplos:

textos aparecendo suavemente;

páginas fazendo fade;

objetos abrindo;

pequenos movimentos de cursor;

transições entre documentos;

elementos que mudam quando o mouse passa;

sons opcionais, mas desligados por padrão.

Não usar animações exageradas.

RESPONSIVIDADE

O site precisa funcionar perfeitamente em:

desktop;

celular;

tablet.

No celular, a experiência deve continuar parecendo intencional e não apenas uma versão comprimida do desktop.

ARQUITETURA TÉCNICA

Construa o projeto de maneira organizada e escalável.

Quero poder adicionar posteriormente:

cartas;

fotos;

vídeos;

áudios;

textos;

novas memórias;

novos registros;

acontecimentos futuros.

Estruture os dados de maneira que esses conteúdos possam ser adicionados sem precisar reconstruir a interface.

Use componentes reutilizáveis.

Crie dados mockados inicialmente para demonstrar a experiência, mas deixe claro no código onde posso substituir esses dados pelos conteúdos reais.

IMPORTANTE SOBRE O CONTEÚDO

Não invente histórias específicas sobre mim e Júlia.

Use textos de placeholder elegantes, por exemplo:

“[escreva aqui uma lembrança específica]”

“[adicione aqui algo que ela fez e que você nunca esqueceu]”

“[escreva aqui uma carta]”

O conteúdo real será colocado depois.

QUALIDADE

Quero que o resultado pareça um projeto digital cuidadosamente desenvolvido, não um template de Lovable.

Priorize:

identidade;

experiência de navegação;

tipografia;

espaçamento;

microinterações;

responsividade;

facilidade de adicionar conteúdo.

Antes de adicionar novas funcionalidades, certifique-se de que a experiência principal esteja visualmente muito bem resolvida.

Crie agora a primeira versão funcional completa dessa experiência, com todas as páginas e interações principais, usando conteúdo fictício apenas como demonstração.
